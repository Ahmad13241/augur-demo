Augur — League of Legends Opponent Prep

Augur turns public Riot match history into descriptive opponent-prep briefs for coaches and analysts. It supports draft prep, VOD review, and player-pool scouting — it is not a live-game assistant and it does not automate drafts.

What it does

For a roster the analyst has already verified, Augur pulls public match history from the Riot API, summarizes champion pools and role tendencies, and renders a coach-facing packet. The packet surfaces draft pressure points, per-role player cards, and concrete review questions — keyed to ban decisions and VOD timestamps the staff can check before a match.

  • Roster-gated: only runs for accounts whose identity the analyst has verified.
  • Descriptive only: no predictive pick scores and no draft commands.
  • Read-only on the Riot API: account-v1 for identity, match-v5 for history.

What it is not

Not a live-game assistant

Augur never reads live client or spectator data. Packets are generated before a match, from post-game match history, and read by humans.

Not draft automation

Augur does not recommend picks or bans. Its output is analyst-readable notes ("target-ban pressure on X"), never instructions to the draft tool.

No competitive advantage in-game

No overlay, no client hook, no real-time input. The packet is a prep document — the same thing an analyst would build by hand, just faster.

No mass scraping

Crawls are scoped to a single verified opponent roster per packet, with match counts capped and a read-only, rate-limit-aware client.

Who it is for

  • Head coaches & analysts preparing for a specific upcoming match.
  • Player-pool scouts needing a quick read on an opponent roster.
  • VOD reviewers using the packet to prioritize which clips to study.

Privacy posture

  • Uses only the public Riot API (account-v1, match-v5) with an approved key.
  • Identity for each roster slot is reviewed by the analyst before a crawl runs; unverified slots produce a "do not build a draft plan around this player" note, not fabricated history.
  • No private team data is required for the public demo.
  • Generated packets are distributed directly to coaching staff; raw collection artifacts and internal account identifiers are not shared publicly. This page does not expose them.

Riot API compliance

Augur operates as a read-only analyst assistant on top of the public Riot API. It is a private tool for a single analyst/coach workflow, not a public-facing product, not a user-authentication service, and not a gameplay product. Rate limiting, error handling, and retry behavior follow Riot's published guidance. No attempt is made to bypass or supplement the API surface.

Questions: contact the maintainer before relying on this tool in a production match prep workflow.
